# AirLibrary WhatsApp Bot

A WhatsApp bot for managing personal book libraries with Google Sheets integration and image processing capabilities.

  - Key features: Multi-file auth state, QR code generation, message handling

## Current Features

### User Management
- Admin approval system
- User-specific Google Sheets
- Persistent user data storage

### Book Management
1. **Image Processing**
   - Book cover image upload
   - OCR text extraction
   - Title and author detection

2. **Library Management**
   - Add books via images
   - Search books by title/author
   - List all books
   - Delete books
   - Batch processing support

3. **Google Integration**
   - Automatic sheet creation per user
   - Real-time sheet updates
   - Image storage in Google Drive
   - Master sheet for user management

4. **Commands**
   - `help` - Show available commands
   - `search <title>` - Search books
   - `list` - Show all books
   - `delete <title>` - Remove a book
   - `finish` - Process queued images
   - `approve <number>` - Admin command to approve users
   - `show approved` - List approved users

## Potential Failure Points for 100 Concurrent Users

### 1. WhatsApp Connection
- **Issue**: Single connection handling all users
- **Risk**: Connection drops affect all users
- **Mitigation**: Implement connection pooling or multiple bot instances

### 2. Google API Rate Limits
- **Issue**: Vision API and Sheets API have quotas
- **Risk**: Exceeding quotas blocks all users
- **Mitigation**: 
  - Implement rate limiting
  - Queue system for API calls
  - Multiple service accounts

### 3. Memory Management
- **Issue**: In-memory storage of user data
- **Risk**: Memory overflow with many users
- **Mitigation**: 
  - Implement database storage
  - Cache management
  - Regular cleanup

### 4. Image Processing
- **Issue**: Sequential image processing
- **Risk**: Slow processing with many images
- **Mitigation**:
  - Implement parallel processing
  - Image queue system
  - Optimize image sizes

### 5. File System
- **Issue**: Local file storage for auth and data
- **Risk**: File system bottlenecks
- **Mitigation**:
  - Use cloud storage
  - Implement proper file locking
  - Regular cleanup

### 6. Error Handling
- **Issue**: Global error handling
- **Risk**: One error affects all users
- **Mitigation**:
  - Per-user error isolation
  - Better error recovery
  - Monitoring system

### 7. Authentication
- **Issue**: Single auth state
- **Risk**: Auth issues affect all users
- **Mitigation**:
  - Multiple auth states
  - Better session management
  - Auth state recovery

## Required Environment Variables
```
GEMINI_API_KEY=your_gemini_api_key
GOOGLE_APPLICATION_CREDENTIALS=path_to_service_account.json
```

## Setup Instructions
1. Install dependencies: `npm install`
2. Set up environment variables
3. Place service account JSON in root directory
4. Run the bot: `npm start`
5. Scan QR code with WhatsApp
6. Send "help" to see available commands
